# oh-my-auggie (OMA)

**Augment Code auggie CLI를 위한 멀티 에이전트 오케스트레이션.**

> 이 현지화 요약은 [영문 표준 README](README.md)와 동일한 검증된 명령을 사용합니다. 요구 사항, 관리 파일, 안전 및 업데이트 정보는 영문 문서에서 관리됩니다.

## Quick Start

Auggie 네이티브 플러그인 설치를 권장합니다.

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Auggie 안에서 다음을 실행합니다.

```text
/oma:help
/oma:version
/oma:doctor
```

`/oma:help`에 `/oma:*` 명령이 표시되고 `/oma:doctor`가 진단 보고서를 출력하면 성공입니다.
