# oh-my-auggie (OMA)

**Orchestration multi-agent pour la CLI auggie d'Augment Code.**

> Ce resume localise utilise les memes commandes verifiees que le [README anglais canonique](README.md). Les prerequis, fichiers geres, consignes de securite et mises a jour y sont maintenus.

## Quick Start

L'installation native du plugin Auggie est recommandee :

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Puis, dans Auggie :

```text
/oma:help
/oma:version
/oma:doctor
```

L'installation est observable lorsque `/oma:help` affiche les commandes `/oma:*` et `/oma:doctor` imprime son rapport de diagnostic.
