# oh-my-auggie (OMA)

**Dieu phoi da tac nhan cho Augment Code auggie CLI.**

> Ban tom tat ban dia hoa nay dung cung cac lenh da duoc xac minh nhu [README tieng Anh chuan](README.md). Yeu cau, tep duoc quan ly, an toan va cap nhat duoc duy tri tai do.

## Quick Start

Nen cai dat plugin Auggie goc:

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Sau do, trong Auggie:

```text
/oma:help
/oma:version
/oma:doctor
```

Cai dat thanh cong khi `/oma:help` liet ke cac lenh `/oma:*` va `/oma:doctor` in bao cao chan doan.
