# oh-my-auggie (OMA)

**面向 Augment Code auggie CLI 的多智能体编排。**

> 此本地化摘要使用与[规范英文 README](README.md)相同的已验证命令。前置条件、托管文件、安全和更新说明均在英文版维护。

## Quick Start

推荐安装 Auggie 原生插件：

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

然后在 Auggie 中运行：

```text
/oma:help
/oma:version
/oma:doctor
```

当 `/oma:help` 列出 `/oma:*` 命令且 `/oma:doctor` 输出诊断报告时，安装成功。
