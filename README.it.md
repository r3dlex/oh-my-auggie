# oh-my-auggie (OMA)

**Orchestrazione multi-agente per la CLI auggie di Augment Code.**

> Questo riepilogo localizzato usa gli stessi comandi verificati del [README inglese canonico](README.md). Prerequisiti, file gestiti, sicurezza e aggiornamenti vengono mantenuti li.

## Quick Start

E consigliata l'installazione del plugin nativo Auggie:

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Poi, dentro Auggie:

```text
/oma:help
/oma:version
/oma:doctor
```

L'installazione e verificabile quando `/oma:help` elenca i comandi `/oma:*` e `/oma:doctor` stampa il rapporto diagnostico.
