# oh-my-auggie (OMA)

**Orquestracao multiagente para a CLI auggie da Augment Code.**

> Este resumo localizado usa os mesmos comandos verificados do [README canonico em ingles](README.md). Pre-requisitos, arquivos gerenciados, seguranca e atualizacoes sao mantidos la.

## Quick Start

A instalacao do plugin nativo do Auggie e recomendada:

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Depois, dentro do Auggie:

```text
/oma:help
/oma:version
/oma:doctor
```

A instalacao funciona quando `/oma:help` lista os comandos `/oma:*` e `/oma:doctor` imprime o relatorio de diagnostico.
