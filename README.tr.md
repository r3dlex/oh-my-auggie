# oh-my-auggie (OMA)

**Augment Code auggie CLI icin cok ajanli orkestrasyon.**

> Bu yerellestirilmis ozet, [kanonik Ingilizce README](README.md) ile ayni dogrulanmis komutlari kullanir. Gereksinimler, yonetilen dosyalar, guvenlik ve guncelleme bilgileri orada tutulur.

## Quick Start

Yerel Auggie eklentisi kurulumu onerilir:

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Ardindan Auggie icinde:

```text
/oma:help
/oma:version
/oma:doctor
```

`/oma:help` `/oma:*` komutlarini listeler ve `/oma:doctor` tani raporunu yazdirirsa kurulum basarilidir.
