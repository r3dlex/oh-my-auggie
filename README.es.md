# oh-my-auggie (OMA)

**Orquestacion multi-agente para la CLI auggie de Augment Code.**

> Este resumen localizado usa los mismos comandos verificados que el [README canonico en ingles](README.md). Los requisitos, archivos gestionados, seguridad y actualizaciones se mantienen alli.

## Quick Start

Se recomienda instalar el plugin nativo de Auggie:

```bash
auggie plugin marketplace add r3dlex/oh-my-auggie
auggie plugin install oma@oh-my-auggie
auggie
```

Despues, dentro de Auggie:

```text
/oma:help
/oma:version
/oma:doctor
```

La instalacion funciona cuando `/oma:help` muestra los comandos `/oma:*` y `/oma:doctor` imprime el informe de diagnostico.
