# SDLC Path: Brownfield Adoption

## Repository
`oh-my-auggie` — standalone node/TypeScript CLI tool (depth 0).

## Path chosen
**Brownfield adoption** — the repo already has a partial v3 scaffold (`.ai/rules/`,
`.ai/skills/`, `.ai/system-prompts/`, `.ai/drift/`, `.memory/`, `docs/architecture/`,
`docs/specifications/`, `docs/learning/`, ADR-0001) generated by an earlier
`ai-sdlc-init` run. The v3 upgrade adds the missing governance layers additively
without modifying or deleting existing content.

## Rationale
- Existing `.ai/matrix.json` already declares `topology_type: standalone`,
  `current_depth: 0`, `sync_strategy: physical-copy` — correct for this repo.
- `.memory/human-override/` is populated; terminal priority is maintained.
- CI (GitHub Actions) is already configured; no hosted branch-policy mutations
  needed (`protected main`, PR-only delivery).
- The repo is not a skills catalog — skill-modernization branch is inapplicable.
- Cascade is inapplicable (standalone topology has no managed child repos).

## Key decisions
| Decision | Choice | Reason |
| --- | --- | --- |
| Topology | standalone, depth 0 | Single-repo node CLI tool; no umbrella. |
| Sync strategy | physical-copy | Canonical per `modules/sync.md`; symlinks/submodules rejected. |
| Tracker | GitHub Issues (hosted) | `r3dlex/oh-my-auggie` is on GitHub; PR-only delivery on protected `main`. |
| Cascade | no-op | Standalone topology; no managed child repos. |
| Skill catalog | excluded | This repo is not a skill catalog. |
| Example evalsets | not shipped | No shippable AI surface requiring graded evaluation at upgrade time. |
